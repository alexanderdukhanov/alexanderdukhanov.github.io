# Alexander Dukhanov — Actor Portfolio

A static, bilingual (English/German) actor portfolio prepared for GitHub Pages.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — EN/DE language switcher
- `assets/portrait.jpg` — portrait
- `assets/full-body.jpg` — full-body photo

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and the `assets` folder, keeping the same structure.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

The site will then be available at a GitHub Pages address based on the repository/account name.
